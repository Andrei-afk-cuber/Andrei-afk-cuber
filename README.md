## 👋 About Me

I'm a **4th-year Software Engineering student** at the **Belarusian National Technical University (BNTU)** and an aspiring **Python backend developer**.

I picked backend development because it's logical, structured, and leaves plenty of room to grow. Since 2023 I've been going deep into Python and its web ecosystem, and I've completed the **Python Backend Developer** course by **SkyPro**.

What I care about:

- 🧱 **Clean architecture** — readable code, clear separation of concerns, sensible API design
- 🧪 **Reliability** — tests with Pytest and automated checks in CI
- 📦 **Reproducibility** — containerized setups with Docker and docker-compose
- 📚 **Learning** — I read documentation first and ask good questions second

**What I'm looking for right now:** my first commercial experience in a team, ideally under the guidance of an experienced mentor, where I can contribute from day one and grow quickly.
